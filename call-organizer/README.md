# 📞 Call Organizer

A responsive contact management web app built with **Vanilla JavaScript**, inspired by a JavaScript course project and redesigned with my own interface, layout, and additional functionality.

## ✨ Features

- 📇 Create and manage contact cards
- 💾 Persistent storage using Local Storage
- 🎨 Custom dark UI with responsive design
- 📱 Mobile-friendly layout
- 🏷️ Category-based organization
  - Emergency
  - Urgent
  - Important
  - No Rush
- 🔍 Category filtering
- ⬆️⬇️ Reorder contact cards
- 🖱️ Interactive hover effects
- 🔔 Toast notifications for upcoming features
- ✂️ Automatic text truncation for long names

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API

## 📚 What I Learned

While building this project, I practiced:

- Dynamic DOM creation
- Event handling
- Local Storage
- Responsive design
- Flexbox & CSS Grid
- UI polishing and debugging
- Component-based thinking in Vanilla JavaScript


## 📌 Notes

The core project idea came from a JavaScript course, but the interface, responsive layout, visual styling, interaction details, and several features were redesigned and implemented independently as part of my learning process.
